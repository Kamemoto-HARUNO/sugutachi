# モード切替・モバイルメニューの未読バッジ

2026-09-10。ローカル実装。開発環境・本番への反映は別途。

- 「利用するモード」の各行に、そのモードの未読合計を表示する。
- 三本ラインメニューには現在のモードの未読合計を表示する。通知・メッセージの各リンクは従来どおり個別件数を表示する。
- 合計は未読DM・予約メッセージ数と未読通知カード数。ただし未読メッセージがある会話の受信通知カードは重ねて数えない。例：未読メッセージ2通、その会話の通知1カード、別のお知らせ1件なら合計3件。
- 共通通知は各モードの件数に含む。役割間の合計は表示しない。0件はバッジなし、100件以上は99+。読み上げ用ラベルは実件数を伝える。
- 取得するのは認証アカウントの有効・未失効の役割の件数のみ。相手の名前、本文、画像、会話IDはサマリーに含めない。
- `/api/me/unread-summary` を共通の通知Providerで取得し、各画面のバッジへ供給する。従来のメッセージリンクごとの予約一覧取得・個別ポーリングは廃止する。
- 既読イベント・通知既読操作・メニューを開く操作・画面への復帰で更新する。表示中は30秒間隔でも更新する。遅い応答が新しい結果や別ログインの件数を上書きしないよう保護する。
- DMの期限切れ・削除済み内容と、利用者が閲覧できなくなった予約メッセージはメッセージ件数に含めない。未読の通知カード自体が残る場合は通知として数える。
- DBスキーマ変更・既読状態の一括変更・通知配信設定変更はない。

検証：394テスト（3,412 assertions）成功、型チェック・ビルド成功。役割分離／失効／未認証／他アカウント除外、逆役割DM、通知との重複除外、既読後の件数、閲覧停止済み予約、削除・期限切れDMを検証。ローカルで320/390px・PC表示、モード切替、キーボード開閉、0件・99+を確認。

全体テストはローカル確認用のサイト名・URLの影響を避け、次の設定で実行：

```sh
APP_NAME='すぐタチ' APP_URL=http://localhost SERVICE_BASE_URL=https://sugutachi.com php artisan test --compact
```

ローカル確認先：http://127.0.0.1:8018/ 。既存の専用確認アカウントに未読DM2通を追加（外部配信なし）。モード一覧とモバイルメニューから確認できる。
